# SpeakCheck — конкуренты и незанятая ниша

Дата чтения всех источников: **2026-11-09**. Только публичные источники. Цены в приложениях взяты из списка встроенных покупок App Store, в основном из **киргизской витрины** (apps.apple.com/kg, цены в USD). Если в KG приложения нет, используется другая витрина, и это указано. Курс для пересчёта: НБКР на 06.11.2026, **1 USD = 87.4493 сом, 1 RUB = 1.0699 сом** ([economist.kg](https://economist.kg/dengi/2026/11/05/kursy-valyut-2026-11-06/)).

Главный вывод одной строкой: **ниша узкая, но формально не занята.** Ни один найденный продукт не сочетает сразу оценку каждого звука, объяснение ошибок на русском и контент под IELTS Speaking с датой экзамена. Но три продукта закрывают по две из трёх частей: IELTSpeaking, BoldVoice и Praktika. Быстрее всех SpeakCheck может повторить Praktika.

## 2. Ценовой диапазон

**A. Приложения: самый дешёвый тариф с подписью «месяц»** (витрина KG, USD; у Stimuler витрина UZ):

| Приложение | $/мес |
|---|---|
| Speakometer | 0.99 |
| Stimuler | 2.99 |
| ELSA Speak | 5.99 |
| ChatGPT Go | 5.99 |
| IELTS Prep Band 9 | 8.99 |
| Praktika | 9.99 |
| Speak | 9.99 |
| IELTSpeaking | 29.99 |

- **Минимум:** $0.99. **Максимум:** $29.99 (IELTSpeaking).
- **Медиана** восьми значений: (5.99 + 8.99) / 2 = **$7.49/мес ≈ 655 сом**.
- Если добавить BoldVoice «Premium» за $14.99 (срок в списке не подписан), значений будет девять и медиана станет **$8.99 ≈ 786 сом**.

**B. Годовые тарифы в пересчёте на месяц** (самый дешёвый тариф с подписью «год», делённый на 12):
Speakometer 3.99/12 = 0.33 · Praktika «Annual» 19.99/12 = 1.67 · Stimuler 22.99/12 = 1.92 · IELTS Prep 29.99/12 = 2.50 · ELSA «1 year» 44.99/12 = 3.75 · Speak 49.99/12 = 4.17 · BoldVoice 89.99/12 = 7.50 · IELTSpeaking 99.99/12 = 8.33.
- **Минимум** $0.33, **медиана** (2.50 + 3.75) / 2 = **$3.13/мес**, **максимум** $8.33/мес.
- Оговорка: у многих приложений в списке по несколько годовых цен. Это A/B-тесты и промо, поэтому самая дешёвая цена может показываться не каждому.

**C. Живые преподаватели и курсы** (в месяц, пересчёт по курсу НБКР):
- Skyeng «Гибкий»: 3000 ₽ × 1.0699 = 3 210 сом → **$36.70**
- ielts.kg: 4285 сом → **$49.00**
- MLDC АУЦА: 10500 / 2 = 5250 сом → **$60.03**
- Logos, группа: 9000 сом → **$102.92**
- Skyeng «Базовый»: 10 490 ₽ × 1.0699 = 11 223 сом → **$128.34**
- Preply: $17 × 8 занятий (2 в неделю) → **$136**
- Logos, мини-группа: 12000 сом → **$137.22**

Итог: минимум **$36.70**, медиана **$102.92**, максимум **$137.22**. Живая подготовка стоит в 5–15 раз дороже медианного приложения. Это «потолок», с которым покупатель в Бишкеке сравнивает цену.

## 3. Карта позиционирования (текстом)

- **Ось X:** глубина обратной связи по произношению (нет → общий балл → балл по слову → **балл по каждому звуку с объяснением**).
- **Ось Y:** насколько продукт подходит к IELTS или собеседованию **для русскоязычного** (нет → только IELTS на английском → русский интерфейс → **IELTS/собеседование + объяснения на русском**).

```
 Y: IELTS/собеседование + русский
  ▲
  │  Курсы Бишкека      IELTSpeaking(?)          ★ SpeakCheck (цель)
  │  (Logos, АУЦА,      [рус. UI + IELTS,
  │   ielts.kg)          звуки не проверены]
  │  Skyeng             Praktika
  │                     [рус. объяснения, IELTS,
  │                      загрузка PDF/резюме]
  │  ChatGPT voice
  │                     Stimuler   IELTS Prep B9    ELSA [звуки + IELTS
  │                     [IELTS, англ.]               в Premium, англ. UI]
  │                                                 BoldVoice [звуки, рус. UI,
  │                                                  нет IELTS, амер. акцент]
  │  YouTube, друг      Duolingo     Speak          Speakometer [звуки, англ.]
  └──────────────────────────────────────────────────────────────────────► X
     нет обратной связи   общий балл     балл по слову     балл по звуку
```

В правом верхнем углу (звуки + русский + IELTS) нет ни одного **проверенного** игрока. Ближе всех к нему стоят IELTSpeaking (сверху, но насколько детальна оценка звуков, из описания не видно), BoldVoice и ELSA (справа, но без русских объяснений и, у BoldVoice, без IELTS) и Praktika (по центру, но это разговорный тренажёр).

## 5. Незанятая ниша

**Чего никто не делает хорошо, с доказательствами:**

1. **Разбор по звукам, объяснённый на русском, с подсказкой, как исправить.**
   - Звуки разбирают ELSA, BoldVoice и Speakometer. У ELSA и Speakometer интерфейс только английский (по карточкам [ELSA KG](https://apps.apple.com/kg/app/id1083804886) и [Speakometer KG](https://apps.apple.com/kg/app/id1529508890)).
   - Пользователи прямо жалуются: «нет русского» (тема 7) и «не объясняет, как исправить» (тема 5).
   - У BoldVoice есть русский интерфейс и план под родной язык, но **объясняет ли он ошибки на русском, по описанию не видно** (не проверено).
2. **Именно отработка произношения.** Лидер ушёл в ИИ-разговоры, и его пользователи недовольны: ~12 отзывов о том, что ELSA после редизайна перестала разбирать звуки (тема 3). Значит, на «простой и быстрый тренажёр произношения» есть спрос, который ELSA сейчас не закрывает.
3. **IELTS Speaking + русский + произношение на уровне звуков в одном продукте.**
   - IELTSpeaking: русский интерфейс и IELTS, но произношение — одна строка в общем балле. Разбор по фонемам в описании не заявлен (не проверено).
   - Stimuler и IELTS Prep Band 9: IELTS есть, русского нет.
   - Praktika: русские объяснения, IELTS, собеседования и загрузка своих текстов есть, но это разговорный тренажёр, а оценка по звукам не заявлена.
4. **Цена между приложением и курсом.** Медиана приложений около $7.5/мес, курсы в Бишкеке $49–137/мес. «Подготовка к IELTS Speaking с датой экзамена» за 500–1000 сом/мес попадает в пустой ценовой коридор.

**Честные оговорки, почему ниша может оказаться меньше, чем кажется:**
- **Это ниша на стыке функций, а не новая функция.** Каждую часть уже кто-то делает. Защита держится только на сочетании и фокусе на русскоязычных.
- **IELTSpeaking нужно проверить руками** (скачать и пройти тест). Если там уже есть разбор по звукам на русском, ниши почти нет.
- **В IELTS произношение — только 1 из 4 критериев.** IELTSpeaking и Stimuler дают оценку всех четырёх критериев (band). SpeakCheck закрывает только произношение, и покупатель может посчитать это «половиной подготовки».
- Оценка Azure — не балл IELTS. В ELSA точность — источник недоверия (тема 4), и SpeakCheck рискует так же.

**Чем SpeakCheck может владеть:** «Тренажёр произношения для IELTS Speaking и собеседования, который объясняет каждую ошибку по-русски — на твоём тексте, к дате экзамена». Плюс надёжность: тема 1 — самая массовая жалоба на лидеров.

## 6. Угроза: кто скопирует быстрее всех

1. **Praktika — самая большая угроза.**
   - Уже есть: русский интерфейс, объяснения на родном языке, уроки IELTS/TOEFL и собеседований, загрузка PDF, фото и резюме ([KG карточка](https://apps.apple.com/kg/app/id1624701477)), №25 в Education в KG.
   - Деньги: Series A на $32.5M ([FinSMEs, 2024](https://finsmes.com/2024/05/praktika-raises-32-5m-in-series-a-funding.html); в других источниках $35.5M).
   - Чего не хватает до SpeakCheck: экрана с оценкой каждого звука и цели с датой экзамена. Это одна фича.
   - Как скопирует: добавит режим «Pronunciation check» в существующие уроки IELTS.
2. **IELTSpeaking.** Уже есть русский интерфейс, IELTS, ответы Band 6/7, а цена Pro $29.99/мес даёт запас маржи. Подключить разбор по фонемам (тот же Azure) и объяснения на нужном языке через LLM — работа на недели.
3. **ELSA.** Звуки и IELTS уже есть, нет русского. Локализация и объяснения через LLM — это перевод. Но ELSA сейчас занята ИИ-разговорами и жалобами на редизайн, поэтому, скорее всего, будет медленной.
4. **Любой инди-разработчик.** Azure Pronunciation Assessment и LLM общедоступны, сам движок оценки не защищает. Пример: IELTS Prep Band 9 — небольшой разработчик с 306 оценками в KZ.

**Вывод по угрозе:** функциональный отрыв SpeakCheck копируется за 1–3 месяца. Защищать придётся тем, что не копируется быстро: локальной дистрибуцией в Бишкеке (учителя, центры IELTS, Telegram-каналы), контентом под русскоязычные ошибки (θ/ð, w/v, редукция гласных) и ценой в сомах ниже курсов.
