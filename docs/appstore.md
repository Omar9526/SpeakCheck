## Описание

Тренируйте английское произношение на своих текстах: рабочих письмах, докладах, учебниках, текстах для собеседования.

Как это работает:
• Загрузите PDF, Word, TXT или сфотографируйте страницу.
• Прочитайте фрагмент вслух.
• Получите оценку 0–100 по точности звуков, беглости, полноте и интонации.
• Посмотрите, какие слова прозвучали неточно, вплоть до отдельных звуков.
• Прочитайте объяснение ошибок на русском и повторите трудное слово.

Каждый день:
• Серия дней подряд и «Слово дня».
• Личный список трудных слов по вашим реальным попыткам.
• График прогресса и история всех попыток.

С друзьями:
• Карточка с результатом для сторис.
• «Вызов другу»: друг читает тот же текст, и вы сравниваете баллы.

Приватность: запись голоса по умолчанию удаляется сразу после анализа. Можно пользоваться без регистрации.

Оценка — учебный ориентир и не является сертифицированным тестом CEFR/IELTS.

## Заметки для проверки (App Review Notes)

```
The app can be used without an account: tap "Попробовать без входа" (Try without sign-in).
1. Tap a starter text on the Home tab (e.g. "Зачем учить английский").
2. Tap the microphone, read the English text aloud, tap Stop.
3. The result shows a 0–100 pronunciation score per word (Microsoft Azure Pronunciation Assessment)
   and explanations in Russian.
Account deletion: Profile → "Удалить все мои данные".
Audio is deleted from our server right after analysis unless the user enables "Хранить мои записи".
```
