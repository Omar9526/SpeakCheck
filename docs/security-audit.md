## Проверено — уже было в порядке

- **API-ключи:** Azure и DeepSeek только на сервере в `.env`; в iOS-бинарнике их нет (проверено `strings` по Release-сборке).
- **История Git:** все коммиты просканированы на ключи (OpenAI/DeepSeek `sk-`, AWS, GitHub, Google, приватные ключи, JWT, `KEY=`/`SECRET=`/`PASSWORD=`). Утечек нет, `.env` ни разу не коммитился → **заменять нечего**.
- **Пароли:** в SpeakCheck паролей нет (вход через Apple или гостем), у пользователей `set_unusable_password()`. Пароль БД — только в `deploy/.env`.
- **Чужие данные (IDOR):** все запросы фильтруются по владельцу; чужие документы, попытки, оценки, вызовы → 404.
- **SQL-инъекции:** только Django ORM (параметризованные запросы), сырого SQL нет.
- **Загрузка файлов:** только WAV PCM 16 кГц/16 бит/моно по сигнатуре и заголовку, ≤90 с, тело ≤25 МБ (Caddy — 30 МБ); файлы в приватном томе с правами 0600, путь защищён от `../`. PDF/DOCX/фото разбираются на устройстве (защита от zip-бомб и XXE).
- **XSS:** пользовательский текст на публичной странице экранируется.
- **Админка:** Django admin не установлен — `/admin/` → 404.
- **Режим отладки:** по умолчанию выключен; в Docker принудительно `DJANGO_DEBUG=0`; без секретного ключа продакшн не стартует.
- **HTTPS:** Caddy с Let's Encrypt + HSTS; `manage.py check --deploy` без замечаний.
- **Зависимости:** `pip-audit` — известных уязвимостей нет.
- **Оплата и цены:** в приложении нет платежей. Когда появится подписка — проверять чеки App Store только на сервере (App Store Server API).
